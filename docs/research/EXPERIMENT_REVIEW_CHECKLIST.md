# OpenRGD Experiment Review Checklist

Before changing a study from DESIGN_DRAFT to REVIEW_READY:
- [ ] RQ identifies an actual unknown and decision it would change
- [ ] H1/H0 or primary rival mechanism are explicit
- [ ] Comparator and units of analysis defined
- [ ] Primary endpoint operationalized with timebase and measurement uncertainty
- [ ] Sample size and design justified for the claim scope
- [ ] Trial order/seeds, inclusion/exclusion, aborts and missing-data treatment fixed
- [ ] Analysis code/method and uncertainty interval defined
- [ ] Instrumentation and negative controls actually ready
- [ ] Owner, safety authorization and no-effect boundaries independently checked
- [ ] Consent and private data policy reviewed
- [ ] Upstream prior evidence marked retrospective if already observed
- [ ] Independent reviewer approves the exact version
- [ ] Source/analysis code and future data retention plan pinned

Before setting PREREGISTERED:
- [ ] All above complete; no placeholder method gaps
- [ ] Immutable externally verifiable or independently timestamped snapshot
- [ ] Registration timestamp clearly precedes new confirmatory data
- [ ] Record frozen protocol hash, ID, approval and amendment policy

Before publishing results:
- [ ] All raw and omitted trials accounted for
- [ ] No fabricated scientific significance, independent replication or hardware certification
- [ ] Protocol deviations and exploratory analyses labeled separately
- [ ] Reproducible code, data provenance and confidence/uncertainty included
- [ ] Negative outcomes, safety aborts, unavailable evidence and privacy restrictions documented
- [ ] Thesis status and public article accurately reflect the measured scope
